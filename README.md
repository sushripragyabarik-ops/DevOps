# AWS & DevOps Projects

Hands-on projects exploring AWS cloud services, serverless data pipelines,
CI/CD automation, containerization, and Kubernetes-based deployment.

## Projects

### AWS Serverless Data Pipeline
An end-to-end serverless data pipeline using AWS services for ingestion,
processing, transformation, cataloging, monitoring, and notifications.

**Technologies:** Amazon S3, AWS Lambda, AWS Glue, EventBridge,
CloudWatch, SNS, IAM

### Jenkins + Docker + Kubernetes CI/CD
An end-to-end CI/CD workflow for building, containerizing, and deploying
an application using Jenkins, Docker, Amazon ECR, Kubernetes/EKS, Helm,
and Argo CD.

**Technologies:** Jenkins, Docker, Amazon ECR, Kubernetes, Amazon EKS,
Helm, Argo CD
